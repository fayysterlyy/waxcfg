WaxCfg

io.github.waxcfg · MIT · Fabric

A config library for Fabric mods. Typed TOML configs, versioned migration, and an in-game editor screen. Its only runtime dependency is Fabric API.

Requires: Minecraft 26.2 · Fabric Loader 0.17+ · Java 21+

Usage

For players. Developers: see the gradle snippet below.

  1. Install Fabric Loader for Minecraft 26.2.
  2. Drop Fabric API (0.154.2+26.2) into .minecraft/mods.
  3. Drop waxcfg-1.4.0.jar into .minecraft/mods.
  4. Launch the game. The config screen opens from Mod Menu → WaxCfg.
build.gradle — for mod developers 
repositories {
    maven { url = "https://api.modrinth.com/maven" }
}

dependencies {
    // include as a dependency of your own mod
    modImplementation "maven.modrinth:waxcfg:1.4.0"
}

FAQ

Anything else — GitHub issues.

What is 26.2? Didn't Minecraft skip 1.21.x?

Minecraft moved to year-based versioning in 2026 — releases now go 26.1, 26.2, 26.3. WaxCfg 1.4.0 targets 26.2 only; the 26.1 builds are listed above and unsupported.

Does it need Fabric API?

Yes, 0.154.2+26.2. That's the only runtime dependency — WaxCfg doesn't load without it.

My launcher says Fabric is already installed.

Some launchers bundle their own loader. If yours does, skip step 2 — but keep Fabric API in your mods folder.

Can my mod depend on it?

Yes. Add the Modrinth maven repo and the dependency from the snippet above. If you don't want a hard dependency, shade your own config handling instead.

Where is the config file stored?

.minecraft/config/waxcfg.toml — shared between mods that use the library. The in-game editor writes the same file, so external edits are picked up on next reload.
